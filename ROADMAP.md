# Roadmap

## Status

Standards proposal. This repository is the technical implementation proposal
for the [PiRC1 enhancements (PR #2)](https://github.com/PiNetwork/PiRC/pull/2)
— a reference implementation, not a product.

## Sequenced next

1. **Proposal engagement** — respond to PiRC maintainer feedback and iterate
   on the standards doc.
2. **Reference quality** — keep the sample implementation (Sigmoid tier
   logic, usePiUtility) tested and runnable so reviewers can verify it.
3. **Adoption** — document how a dApp adopts the manifest + PEP standards.

## Explicitly out of scope

- Turning this into a standalone product or SDK before the standard is
  adopted upstream.
- Marketing claims beyond what the reference implementation demonstrates.
